Cómo usarlo

  • Marcá cada paso cuando lo viste funcionar. El avance queda guardado en localStorage de este navegador.
  • Usá datos de prueba con prefijo TEST- en clientes, proyectos y notas, así se pueden borrar después.
  • No uses producciones activas: el ciclo mueve estados reales y al validar congela los importes.
  • Si algo falla, anotá: pantalla, acción clickeada, action de la request, payload y respuesta JSON (F12 → Network → exec).
Contraseña de admin: no está en el repositorio, se rotó. Si no la tenés, corré resetAdminPassword desde el editor de Apps Script (utils/resetAdminPassword.gs): genera una nueva y la muestra una sola vez en el log.
